# 东方幻想乡弹幕 · 一面

练手做的弹幕小游戏,一个 HTML 文件,双击就能玩。手机上打开会自动切成触屏模式:按住屏幕拖着走,自动射击。

角色和世界观致敬东方 Project(© Team Shanghai Alice / ZUN)。仓库里没有官方素材,立绘、子弹、音乐都是代码画的、合成的,代码是自己写的。仅供学习交流和个人使用,请支持原作。

## 流程

一面五幕,大概一分半:

- 道中妖精波,然后是中 Boss 琪露诺
- 第二波道中,十六夜咲夜
- 深入红魔馆,关底蕾米莉亚

三个自机(灵梦 / 魔理沙 / 早苗),射击方式和炸弹不一样。难度分简单、普通、困难。符卡、擦弹、残机、火力道具这些都有。

## 操作

电脑:方向键或 WASD 移动,Shift 低速,Z 或 J 射击,X 或 K 放符卡,Esc 暂停。

手机:按住屏幕拖动就是移动,双指按住等于低速,右下角按钮放符卡。切后台会自动暂停。

## 想换立绘或音乐

- 立绘:在 html 旁边建一个 `chars/` 文件夹,放 `reimu.png`、`marisa.png`、`sanae.png`(jpg 也行),刷新就换上了;标题界面也能直接选本机图片。大小和位置在设置里拖。
- 音乐:在 html 旁边建 `bgm/`,放 `title`、`stage`、`boss`、`clear` 四个 mp3(wav / ogg / m4a 都行)。不放就用内置的合成曲。

## 文件

```
index.html     成品,单文件
src/
  head.html    页面骨架和 UI
  10_core.js   配置、工具、音频合成
  20_actors.js 画面自适应、触屏输入、背景和角色绘制
  30_stage.js  玩家和弹幕逻辑、关卡事件表
  40_boss.js   三个 Boss
  50_ui.js     主循环、HUD、界面流转
  _build.ps1   把源码拼成 index.html
  test.js      无头跑一局的回归测试
  _genbgm.js   生成示例 BGM(可选)
```

改完源码重新打包、跑一遍测试:

```powershell
pwsh -File src/_build.ps1
node src/test.js
```

成品不依赖网络,丢到任意静态托管上都能跑。
